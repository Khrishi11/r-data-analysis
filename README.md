# R Data Analysis

Two R projects from the Future Connect data analytics course (2026).

## 1. Bank marketing EDA (`bank-marketing-eda/`)
An R Markdown notebook exploring a Portuguese bank's direct marketing campaign (about 41,000 client records) to understand which client and campaign factors relate to a client subscribing to a term deposit.
- `bank_marketing_eda.Rmd`: source notebook
- `bank_marketing_eda.nb.html`: rendered output, open in a browser to see the charts without running R

## 2. COVID-19 line list (`covid19/`)
`script.R` works through the early COVID-19 patient line list, comparing death rates by age and gender and testing whether the differences are statistically significant.

## 3. Basics (`basics/practice.R`)
Practice script covering R syntax, vectors and data structures.

## Tools
R, RStudio, R Markdown, tidyverse style data wrangling, ggplot2, hypothesis testing
